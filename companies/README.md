# companies/

Each SMM venture gets its own sub-folder here once Phase 3 (venture selection, see [MASTERPROMPT.md](../MASTERPROMPT.md)) names it — its own identity, spec, code, and marketing, kept independent of other ventures and of the internal "SMM" holding name.

Expected shape per venture:
```
companies/<venture-name>/
├── spec.md            # product-designer's output
├── decisions.md        # strategist's decision log for this venture
├── marketing/          # marketer's copy/positioning/launch plan
└── (site/app source, built by web-developer)
```
